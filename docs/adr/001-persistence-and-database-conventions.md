# ADR-001: Consolidated database proposal

The persistence and database conventions draft has been consolidated into
[ADR-001: Database Engine, Data Model and Persistence Conventions](../../ADR-Database-Engine-and-Data-Model.md).

That document is the canonical proposal for the engine, relational model,
migrations, identifiers, timestamps, concurrency/ETags and synthetic seeding.
Its status remains **Proposed**, pending human review and team approval.

This file is retained only to preserve existing links; it is not a separate
decision or evidence of approval.
