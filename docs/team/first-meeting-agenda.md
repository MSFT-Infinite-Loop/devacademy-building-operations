# First team meeting agenda

- **Duration:** 60 minutes

## Required outcomes

- Inputs and approval process for the Team Charter
- Core package ownership
- Two Advanced package selections
- GitHub-first platform decision and access actions
- Working agreements and release-captain rotation
- ADR investigation owners
- Week 1 actions, owners, and deadlines

## Agenda

### 0-5 minutes: opening and objectives

- Confirm the desired outcomes.
- Explain that decisions will be recorded as Agreed, Provisional, Open, or Action required.
- Use a parking lot for topics that require separate investigation.

### 5-13 minutes: strengths, goals, and capacity

Each participant shares strengths, learning objectives, first and second package preferences, realistic weekly availability, and known constraints.

### 13-27 minutes: package ownership

- Assign primary owners for FE, BE, DB, and OPS Core.
- Select two Advanced packages and primary owners.
- Agree how each participant will deliver a vertical slice and review outside their track.

### 27-34 minutes: platform and access

Proposed framing: GitHub for the private monorepo, Issues, Projects, pull requests, Actions, and Releases; approved Azure subscription for hosting.

Decide or assign actions for:

- teammate access and GitHub handles;
- jury access limitations for a personally owned repository;
- GitHub Project ownership;
- Actions budget and controls;
- Azure subscription and deployment identity.

### 34-44 minutes: Charter working agreements

- Team name
- Communication channel and acknowledgement target
- Weekly sync
- Decision-making and conflict resolution
- Pull-request and review rules
- Release-captain rotation
- Definition of Done
- Charter amendment process

### 44-51 minutes: technical decisions and ADR ownership

Assign investigation owners and due dates for frontend framework, API style, database, authentication, caching, and hosting/deployment. Every participant must author at least one ADR.

### 51-57 minutes: Week 1 and Week 2 actions

Assign owners for the Charter, plan, board, M1-M7 epics, branch rules, CI skeleton, local environment, walking skeleton, effort-recording workflow, AI journals, and first release.

### 57-60 minutes: read-back and close

Read back each decision and action. Every action must have an owner and deadline.
